VisionSelector: End-to-End Learnable Visual Token Compression for Efficient Multimodal LLMs

动机

问题背景

MLLM 在处理高分辨率图像、多图像、视频时，视觉令牌数量激增，导致严重的计算和内存瓶颈。然而视觉信息存在显著冗余，有效的令牌压缩可以在保留关键信息的同时提升效率。

现有方法的局限

方法类别 代表工作 局限
基于变换 FocusLLaVA, TokenPacker 固定压缩比，缺乏灵活性，需额外训练
基于注意力 FastV, VisionZip, PruMerge+ 受注意力沉没(Attention Sink)影响，高压缩率下性能急剧下降
基于相似性 DART, DivPrune 可能丢弃细粒度关键信息
通用问题 以上所有 依赖启发式规则，缺乏对下游任务的适应性，泛化能力有限

核心痛点： 现有方法将令牌压缩视为后处理步骤（基于启发式规则），而非可学习的决策过程，无法根据下游任务需求自适应选择关键令牌。

方法

核心思路

将令牌压缩重新构建为端到端可学习的决策过程，由下游损失直接优化选择策略。

整体框架

VisionSelector 是一个即插即用的轻量级模块，部署在模态接口与 LLM 之间：

处理流程：

  1. 模态接口将视觉特征投影为视觉令牌 V∈RN×DV \in \mathbb{R}^{N \times D}V∈RN×D
  2. 可学习重要性评分器(LIS)为每个令牌生成重要性分数 s∈RNs \in \mathbb{R}^Ns∈RN
  3. 可微 Top-K 机制(DTS)基于分数生成软掩码 MsoftM_{soft}Msoft​
  4. 软掩码逐元素乘原始特征：Vpruned=Msoft⊙VV_{pruned} = M_{soft} \odot VVpruned​=Msoft​⊙V
  5. 剪枝后的特征拼接文本令牌送入 LLM

三个关键组件

① 可学习重要性评分器 (LIS)

轻量级双线性投影结构，仅 12.85M 参数：

  • 通过 全局自注意力交互 评估每个令牌的相对重要性
  • 近零初始化 确保与冻结的预训练模型平滑集成

② 可微 Top-K 选择机制 (DTS)

解决 Top-K 离散不可微的问题：

前向： 通过二分法搜索阈值 ttt，使得 ∑σ(si+t)≈k\sum \sigma(s_i + t) \approx k∑σ(si​+t)≈k，得到软掩码 M=σ(s+t)M = \sigma(s + t)M=σ(s+t)

反向： 通过隐式微分计算梯度，无需反向传播搜索过程：

∂M∂s=diag(v)−vvT∑vi\frac{\partial M}{\partial s} = diag(v) - \frac{vv^T}{\sum v_i} ∂s∂M​=diag(v)−∑vi​vvT​

其中 vi=Mi(1−Mi)v_i = M_i(1-M_i)vi​=Mi​(1−Mi​)

性质： 保持 sigmoid 的单调性——高分令牌被提升，低分令牌被抑制。

推理： 直接使用标准 Top-K，高效无开销。

③ 课程退火策略 (CAS)

弥合训练（软选择）与推理（硬选择）之间的差距：

复合损失：

Ltotal=LCE+λtLconstraintL_{total} = L_{CE} + \lambda_t L_{constraint} Ltotal​=LCE​+λt​Lconstraint​

Lconstraint=BCE(Msoft,Mhard)L_{constraint} = BCE(M_{soft}, M_{hard}) Lconstraint​=BCE(Msoft​,Mhard​)

课程退火调度：

λt=λstart+(λend−λstart)×min⁡(tcurrentttotal,1.0)\lambda_t = \lambda_{start} + (\lambda_{end} - \lambda_{start}) \times \min(\frac{t_{current}}{t_{total}}, 1.0) λt​=λstart​+(λend​−λstart​)×min(ttotal​tcurrent​​,1.0)

  • 早期 λt\lambda_tλt​ 较小，模型专注学习下游任务
  • 后期 λt\lambda_tλt​ 线性增大，加强选择约束
  • 软掩码逐渐极化到 0/1，逼近推理时的硬选择

关键特性

  1. 端到端可学习： 由下游损失（CE Loss）直接驱动，自主发现关键令牌，无需启发式规则
  2. 自适应跨压缩率： 仅在固定 20% 训练，推理时可泛化到 5%~100% 任意预算
  3. 轻量即插即用： 12.85M 参数，不修改骨干，兼容 FlashAttention
  4. 天然抗 Attention Sink： 学习到的分数不受注意力沉没偏差影响
  5. 噪声过滤： 在 30% 预算下 MME 达到 100.07% 相对性能（超越全量基线），说明能有效剪枝干扰信息
