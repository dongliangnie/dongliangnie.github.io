熵

熵（Entropy）

熵是信息论中最基础的概念之一，用来度量随机变量的不确定性或信息量的大小。

基本定义

设离散随机变量 XXX 的概率分布为 p(x)p(x)p(x)，则熵定义为：

H(X)=−∑x∈Xp(x)log⁡p(x)H(X) = - \sum_{x \in \mathcal{X}} p(x) \log p(x) H(X)=−x∈X∑​p(x)logp(x)

对于连续变量（微分熵）：

H(X)=−∫p(x)log⁡p(x)dxH(X) = - \int p(x) \log p(x) dx H(X)=−∫p(x)logp(x)dx

信息量

单个事件的信息量定义为：

I(x)=−log⁡p(x)I(x) = -\log p(x) I(x)=−logp(x)

👉 事件越罕见（概率越小），信息量越大

熵就是“平均信息量”：

H(X)=E[−log⁡p(x)]H(X) = \mathbb{E}[-\log p(x)] H(X)=E[−logp(x)]

常见例子

（1）二元变量（伯努利分布）

若：

P(X=1)=p,P(X=0)=1−pP(X=1)=p,\quad P(X=0)=1-p P(X=1)=p,P(X=0)=1−p

则熵为：

H(X)=−plog⁡p−(1−p)log⁡(1−p)H(X) = -p \log p - (1-p)\log(1-p) H(X)=−plogp−(1−p)log(1−p)

条件熵（Conditional Entropy）

定义：

H(X∣Y)=−∑x,yp(x,y)log⁡p(x∣y)H(X|Y) = - \sum_{x,y} p(x,y)\log p(x|y) H(X∣Y)=−x,y∑​p(x,y)logp(x∣y)

👉 表示：在已知 YYY 的情况下，XXX 还剩多少不确定性

联合熵（Joint Entropy）

H(X,Y)=−∑x,yp(x,y)log⁡p(x,y)H(X,Y) = - \sum_{x,y} p(x,y)\log p(x,y) H(X,Y)=−x,y∑​p(x,y)logp(x,y)

重要性质

非负性

H(X)≥0H(X) \ge 0 H(X)≥0

最大值

对于有限状态空间：

H(X)≤log⁡∣X∣H(X) \le \log |\mathcal{X}| H(X)≤log∣X∣

当 XXX 均匀分布时取等号

链式法则

H(X,Y)=H(X)+H(Y∣X)H(X,Y) = H(X) + H(Y|X) H(X,Y)=H(X)+H(Y∣X)

证明

从定义出发，联合熵为：

H(X,Y)=−∑x,yp(x,y)log⁡p(x,y)H(X,Y) = - \sum_{x,y} p(x,y)\log p(x,y) H(X,Y)=−x,y∑​p(x,y)logp(x,y)

条件熵为：

H(Y∣X)=−∑x,yp(x,y)log⁡p(y∣x)H(Y|X) = - \sum_{x,y} p(x,y)\log p(y|x) H(Y∣X)=−x,y∑​p(x,y)logp(y∣x)

利用概率分解公式：

p(x,y)=p(x)p(y∣x)p(x,y) = p(x)p(y|x) p(x,y)=p(x)p(y∣x)

取对数可得：

log⁡p(x,y)=log⁡p(x)+log⁡p(y∣x)\log p(x,y) = \log p(x) + \log p(y|x) logp(x,y)=logp(x)+logp(y∣x)

将其代入联合熵：

H(X,Y)=−∑x,yp(x,y)[log⁡p(x)+log⁡p(y∣x)]H(X,Y) = - \sum_{x,y} p(x,y)\big[\log p(x) + \log p(y|x)\big] H(X,Y)=−x,y∑​p(x,y)[logp(x)+logp(y∣x)]

展开为两部分：

=−∑x,yp(x,y)log⁡p(x)−∑x,yp(x,y)log⁡p(y∣x)= - \sum_{x,y} p(x,y)\log p(x) - \sum_{x,y} p(x,y)\log p(y|x) =−x,y∑​p(x,y)logp(x)−x,y∑​p(x,y)logp(y∣x)

第一项可以化简为：

∑x,yp(x,y)log⁡p(x)=−∑x(∑yp(x,y))log⁡p(x)=−∑xp(x)log⁡p(x)=H(X)\sum_{x,y} p(x,y)\log p(x) = - \sum_x \left(\sum_y p(x,y)\right)\log p(x) = - \sum_x p(x)\log p(x) = H(X) x,y∑​p(x,y)logp(x)=−x∑​(y∑​p(x,y))logp(x)=−x∑​p(x)logp(x)=H(X)

第二项正是条件熵定义：

∑x,yp(x,y)log⁡p(y∣x)=H(Y∣X)\sum_{x,y} p(x,y)\log p(y|x) = H(Y|X) x,y∑​p(x,y)logp(y∣x)=H(Y∣X)

因此得到：

H(X,Y)=H(X)+H(Y∣X)H(X,Y) = H(X) + H(Y|X) H(X,Y)=H(X)+H(Y∣X)

从直观上看，这个公式表示：描述联合变量 (X,Y)(X,Y)(X,Y) 所需的信息量，可以拆解为“先描述 XXX 的信息量”，再加上“在已知 XXX 的条件下描述 YYY 还需要的信息量”。

互信息（Mutual Information, MI）

互信息是信息论中的一个核心概念，用来度量两个随机变量之间共享的信息量。直观来说，它回答的是：

知道变量 XXX 之后，能减少多少关于变量 YYY 的不确定性？

1. 基本定义

设 XXX 和 YYY 是两个随机变量，其互信息定义为：

I(X;Y)=∑x∈X∑y∈Yp(x,y)log⁡p(x,y)p(x)p(y)I(X;Y) = \sum_{x \in \mathcal{X}} \sum_{y \in \mathcal{Y}} p(x,y) \log \frac{p(x,y)}{p(x)p(y)} I(X;Y)=x∈X∑​y∈Y∑​p(x,y)logp(x)p(y)p(x,y)​

对于连续变量：

I(X;Y)=∫∫p(x,y)log⁡p(x,y)p(x)p(y)dxdyI(X;Y) = \int \int p(x,y) \log \frac{p(x,y)}{p(x)p(y)} dx dy I(X;Y)=∫∫p(x,y)logp(x)p(y)p(x,y)​dxdy

2. 等价形式（非常重要）

互信息可以用熵（Entropy）来表示：

I(X;Y)=H(X)−H(X∣Y)I(X;Y) = H(X) - H(X|Y) I(X;Y)=H(X)−H(X∣Y)

I(X;Y)=H(Y)−H(Y∣X)I(X;Y) = H(Y) - H(Y|X) I(X;Y)=H(Y)−H(Y∣X)

I(X;Y)=H(X)+H(Y)−H(X,Y)I(X;Y) = H(X) + H(Y) - H(X,Y) I(X;Y)=H(X)+H(Y)−H(X,Y)

3. 直观理解

（1）信息增益视角

  • H(X)H(X)H(X)：XXX 的不确定性
  • H(X∣Y)H(X|Y)H(X∣Y)：知道 YYY 后 XXX 的剩余不确定性

所以：

I(X;Y)=H(X)−H(X∣Y)I(X;Y) = H(X) - H(X|Y) I(X;Y)=H(X)−H(X∣Y)

👉 表示 Y 提供了多少关于 X 的信息

（2）独立性的判断

如果 XXX 和 YYY 独立：

p(x,y)=p(x)p(y)p(x,y) = p(x)p(y) p(x,y)=p(x)p(y)

则：

I(X;Y)=0I(X;Y) = 0 I(X;Y)=0

👉 没有共享信息

（3）完全相关

如果 X=YX = YX=Y：

I(X;Y)=H(X)I(X;Y) = H(X) I(X;Y)=H(X)

👉 信息完全共享

4. KL散度视角（非常关键）

互信息可以看作联合分布与独立分布的 KL 散度：

I(X;Y)=DKL(p(x,y)∥p(x)p(y))I(X;Y) = D_{KL}\big(p(x,y) \parallel p(x)p(y)\big) I(X;Y)=DKL​(p(x,y)∥p(x)p(y))

👉 含义：

  • 如果 p(x,y)p(x,y)p(x,y) 和 p(x)p(y)p(x)p(y)p(x)p(y) 越接近 → 越独立 → MI 越小
  • 差异越大 → 相关性越强 → MI 越大

5. 性质总结

非负性

I(X;Y)≥0I(X;Y) \ge 0 I(X;Y)≥0

对称性

I(X;Y)=I(Y;X)I(X;Y) = I(Y;X) I(X;Y)=I(Y;X)

与熵的关系

I(X;Y)≤min⁡(H(X),H(Y))I(X;Y) \le \min(H(X), H(Y)) I(X;Y)≤min(H(X),H(Y))
