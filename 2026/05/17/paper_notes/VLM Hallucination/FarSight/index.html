预备知识

注意力坍塌

∑n=1N∑j≤iωn,jl>I(x≤i;xn+1)I(x≤n;xn+1)∑n=1N∑j≤nωn,jl−o(1)\sum_{n=1}^N \sum_{j\le i} \omega_{n,j}^l > \frac{I(x_{\le i};x_{n+1})}{I(x_{\le n};x_{n+1})} \sum_{n=1}^N \sum_{j\le n} \omega_{n,j}^l - o(1) n=1∑N​j≤i∑​ωn,jl​>I(x≤n​;xn+1​)I(x≤i​;xn+1​)​n=1∑N​j≤n∑​ωn,jl​−o(1)

我们要解释：
👉 为什么 attention 的比例 ≈ 信息比例（互信息）
👉 以及为什么会“偏大”（不等式）

1️⃣ 关键起点：互信息的“可加性拆解”

从链式法则出发：

I(x≤n;xn+1)=∑j=1nI(xj;xn+1∣x<j)I(x_{\le n}; x_{n+1})= \sum_{j=1}^{n} I(x_j; x_{n+1} \mid x_{<j}) I(x≤n​;xn+1​)=j=1∑n​I(xj​;xn+1​∣x<j​)

I(x≤n;xn+1)=∑j=1nI(xj;xn+1∣x<j)I(x_{\le n}; x_{n+1})= \sum_{j=1}^{n} I(x_j; x_{n+1} \mid x_{<j}) I(x≤n​;xn+1​)=j=1∑n​I(xj​;xn+1​∣x<j​)

互信息定义为：

I(A;B)=H(B)−H(B∣A)I(A;B) = H(B) - H(B|A) I(A;B)=H(B)−H(B∣A)

所以：

I(x≤n;xn+1)=H(xn+1)−H(xn+1∣x≤n)I(x_{\le n}; x_{n+1})= H(x_{n+1}) - H(x_{n+1} \mid x_{\le n}) I(x≤n​;xn+1​)=H(xn+1​)−H(xn+1​∣x≤n​)

我们引入一串中间项：

H(xn+1∣x≤0),;H(xn+1∣x≤1),;H(xn+1∣x≤2),;…,;H(xn+1∣x≤n)H(x_{n+1} \mid x_{\le 0}),; H(x_{n+1} \mid x_{\le 1}),; H(x_{n+1} \mid x_{\le 2}),; \dots,; H(x_{n+1} \mid x_{\le n}) H(xn+1​∣x≤0​),;H(xn+1​∣x≤1​),;H(xn+1​∣x≤2​),;…,;H(xn+1​∣x≤n​)

注意：

  • x≤0x_{\le 0}x≤0​ 表示“什么都不知道”，即：

    H(xn+1∣x≤0)=H(xn+1)H(x_{n+1} \mid x_{\le 0}) = H(x_{n+1}) H(xn+1​∣x≤0​)=H(xn+1​)

于是可以写：

I(x≤n;xn+1)=H(xn+1∣x≤0)−H(xn+1∣x≤n) I(x_{\le n}; x_{n+1})= H(x_{n+1} \mid x_{\le 0})- H(x_{n+1} \mid x_{\le n}) I(x≤n​;xn+1​)=H(xn+1​∣x≤0​)−H(xn+1​∣x≤n​)

H(xn+1∣x≤0)−H(xn+1∣x≤n)H(x_{n+1} \mid x_{\le 0})- H(x_{n+1} \mid x_{\le n}) H(xn+1​∣x≤0​)−H(xn+1​∣x≤n​)

写成逐步相减：

∑j=1n[H(xn+1∣x<j)−H(xn+1∣x≤j)]\sum_{j=1}^{n} \Big[ H(x_{n+1} \mid x_{<j})- H(x_{n+1} \mid x_{\le j}) \Big] j=1∑n​[H(xn+1​∣x<j​)−H(xn+1​∣x≤j​)]

看其中一项：

H(xn+1∣x<j)−H(xn+1∣x≤j)H(x_{n+1} \mid x_{<j})- H(x_{n+1} \mid x_{\le j}) H(xn+1​∣x<j​)−H(xn+1​∣x≤j​)

注意：

  • x≤j=(x<j,xj)x_{\le j} = (x_{<j}, x_j)x≤j​=(x<j​,xj​)

所以：

H(xn+1∣x<j)−H(xn+1∣x<j,xj)H(x_{n+1} \mid x_{<j})- H(x_{n+1} \mid x_{<j}, x_j) H(xn+1​∣x<j​)−H(xn+1​∣x<j​,xj​)

根据定义：

I(xj;xn+1∣x<j)=H(xn+1∣x<j)−H(xn+1∣x<j,xj)I(x_j; x_{n+1} \mid x_{<j})= H(x_{n+1} \mid x_{<j})- H(x_{n+1} \mid x_{<j}, x_j) I(xj​;xn+1​∣x<j​)=H(xn+1​∣x<j​)−H(xn+1​∣x<j​,xj​)

于是：

I(x≤n;xn+1)=∑j=1nI(xj;xn+1∣x<j)I(x_{\le n}; x_{n+1})= \sum_{j=1}^{n} I(x_j; x_{n+1} \mid x_{<j}) I(x≤n​;xn+1​)=j=1∑n​I(xj​;xn+1​∣x<j​)

2️⃣ attention 的“理想解释”（关键假设）

论文这里隐含了一个建模假设（非常重要）：

attention 权重 ωn,jl\omega_{n,j}^lωn,jl​ ≈ token xjx_jxj​ 对预测 xn+1x_{n+1}xn+1​ 的“贡献权重”

也就是说：

ωn,jl;∝;I(xj;xn+1∣x<j)\omega_{n,j}^l ;\propto; I(x_j; x_{n+1} \mid x_{<j}) ωn,jl​;∝;I(xj​;xn+1​∣x<j​)

👉 这一步不是严格等式，而是：

  • 来自 softmax attention 的信息分配解释
  • 类似很多论文里的 “attention ≈ attribution”

3️⃣ 用这个假设做归一化

对固定 nnn，attention 满足：

∑j≤nωn,jl=1\sum_{j\le n} \omega_{n,j}^l = 1 j≤n∑​ωn,jl​=1

于是可以写成比例关系：

∑j≤iωn,jl∑j≤nωn,jl≈∑j≤iI(xj;xn+1∣x<j)∑j≤nI(xj;xn+1∣x<j)\frac{\sum_{j\le i} \omega_{n,j}^l}{\sum_{j\le n} \omega_{n,j}^l} \approx \frac{\sum_{j\le i} I(x_j; x_{n+1}|x_{<j})}{\sum_{j\le n} I(x_j; x_{n+1}|x_{<j})} ∑j≤n​ωn,jl​∑j≤i​ωn,jl​​≈∑j≤n​I(xj​;xn+1​∣x<j​)∑j≤i​I(xj​;xn+1​∣x<j​)​

利用第1步（链式法则）：

I(x≤i;xn+1)I(x≤n;xn+1)\frac{I(x_{\le i}; x_{n+1})}{I(x_{\le n}; x_{n+1})} I(x≤n​;xn+1​)I(x≤i​;xn+1​)​

4️⃣ 推出“理想情况”

于是得到：

∑j≤iωn,jl≈I(x≤i;xn+1)I(x≤n;xn+1)∑j≤nωn,jl\sum_{j\le i} \omega_{n,j}^l \approx \frac{I(x_{\le i}; x_{n+1})}{I(x_{\le n}; x_{n+1})} \sum_{j\le n} \omega_{n,j}^l j≤i∑​ωn,jl​≈I(x≤n​;xn+1​)I(x≤i​;xn+1​)​j≤n∑​ωn,jl​

再对所有 nnn 求和：

∑n=1N∑j≤iωn,jl≈I(x≤i;xn+1)I(x≤n;xn+1)∑n=1N∑j≤nωn,jl\sum_{n=1}^N \sum_{j\le i} \omega_{n,j}^l \approx \frac{I(x_{\le i}; x_{n+1})}{I(x_{\le n}; x_{n+1})} \sum_{n=1}^N \sum_{j\le n} \omega_{n,j}^l n=1∑N​j≤i∑​ωn,jl​≈I(x≤n​;xn+1​)I(x≤i​;xn+1​)​n=1∑N​j≤n∑​ωn,jl​

👉 这就是等号版本（理想情况）

方法

FarSight 的核心思想是仅通过优化因果掩码实现有效的 token 信息传播，包含两个组件：注意力寄存器（Section 4.1）和位置感知编码（Section 4.2）。

3.1 上三角注意力寄存器

为缓解注意力坍塌，在因果掩码的上三角区域构造注意力寄存器 P∈Rn×n\mathcal{P} \in \mathbb{R}^{n \times n}P∈Rn×n：

Pi=[0,0,…,0⏟i,Pi,i+1,Pi,i+2,…,Pi,n⏟n−i]n\mathcal{P}_i = [\underbrace{0, 0, \ldots, 0}_{i}, \underbrace{\mathcal{P}_{i,i+1}, \mathcal{P}_{i,i+2}, \ldots, \mathcal{P}_{i,n}}_{n-i}]_n Pi​=[i0,0,…,0​​,n−iPi,i+1​,Pi,i+2​,…,Pi,n​​​]n​

每行分配 n−in - in−i 个寄存器注意力分数，用于吸收多余的注意力值。寄存器分数定义为：

Pi,j=−(j−i)⋅σ,∀j>i\mathcal{P}_{i,j} = -(j - i) \cdot \sigma, \quad \forall j > i Pi,j​=−(j−i)⋅σ,∀j>i

其中 σ\sigmaσ 是衰减率超参数。这确保寄存器分数符合注意力的自然衰减模式——距离越远的"未来"位置，寄存器吸收的注意力越少。

将寄存器整合到注意力矩阵中：

W=ω⋅C+P,C=tril(1n×n)W = \omega \cdot C + \mathcal{P}, \quad C = \text{tril}(\mathbf{1}_{n \times n}) W=ω⋅C+P,C=tril(1n×n​)

其中 CCC 是下三角全 1 矩阵，确保原始注意力只保留因果部分。最终注意力计算：

W~=SoftMax(ω⋅C+P⏟W)⋅C\tilde{W} = \text{SoftMax}(\underbrace{\omega \cdot C + \mathcal{P}}_{W}) \cdot C W~=SoftMax(Wω⋅C+P​​)⋅C

关键设计：SoftMax 内部的 P\mathcal{P}P 提供了注意力"吸收槽"——多余的注意力被分散到上三角的寄存器位置；SoftMax 外部的 CCC 将上三角注意力概率清零，保证因果解码性质不被破坏——不会泄露未来 token 信息。

用大白话说：原来 softmax 要求注意力和为 1，outlier token 被迫吸收大量"无处安放"的注意力。现在在上三角开辟了"垃圾桶"位置，多余注意力被导入这些位置后立即清零，有效注意力（下三角部分）的和不再等于 1，从而允许模型将更多注意力集中在真正有用的 token 上。

3.2 位置感知编码

FarSight 的另一个创新是通过渐减遮蔽率在因果掩码中编码绝对位置信息。

设第 iii 行的实际注意力分数和寄存器分数满足：

∑j≤iSoftMaxj=1n(ωi,j)+∑j>iSoftMaxj=1n(Pi,j)=1\sum_{j \leq i} \text{SoftMax}_{j=1}^n(\omega_{i,j}) + \sum_{j > i} \text{SoftMax}_{j=1}^n(\mathcal{P}_{i,j}) = 1 j≤i∑​SoftMaxj=1n​(ωi,j​)+j>i∑​SoftMaxj=1n​(Pi,j​)=1

对于相同输入 token 的序列，实际注意力分数在每行内是均匀的。随着行索引 iii 增大：

  • 因果部分（下三角）可见 token 增多 → 实际注意力分数的指数和累积增大
  • 寄存器部分（上三角）位置减少且衰减 → 寄存器分数的指数和减小

因此有效注意力呈单调递增趋势：

∑j≤iSoftMaxj=1n(ωi,j)<∑j≤i+1SoftMaxj=1n(ωi+1,j)\sum_{j \leq i} \text{SoftMax}_{j=1}^n(\omega_{i,j}) < \sum_{j \leq i+1} \text{SoftMax}_{j=1}^n(\omega_{i+1,j}) j≤i∑​SoftMaxj=1n​(ωi,j​)<j≤i+1∑​SoftMaxj=1n​(ωi+1,j​)

即 W~⋅V=∑i=1nβivi\tilde{W} \cdot V = \sum_{i=1}^n \beta_i v_iW~⋅V=∑i=1n​βi​vi​，满足 β1<β2<⋯<βn=1\beta_1 < \beta_2 < \cdots < \beta_n = 1β1​<β2​<⋯<βn​=1。

直觉：后续位置的 token 自然聚合更多历史上下文，保持有序的信息流动。这种渐进式分配让模型在生成后期仍能对早期 token（特别是视觉 token）保持强关注，增强长程位置感知，有效对抗 RoPE 的长程衰减。
