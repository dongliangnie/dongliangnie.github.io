LLM-JEPA: Large Language Models Meet Joint Embedding Predictive Architectures

  2026-05-19    paper_notes  JEPA    JEPA

1. 问题背景与目标

在大语言模型（LLM）的训练中，标准目标函数通常为自回归语言建模损失 LLLM\mathcal{L}_{\rm LLM}LLLM​，其本质是对输入序列进行逐 token 的条件概率建模。然而，该目标主要关注表层符号重建，对跨模态或跨视图的抽象语义建模能力有限。

为此，引入 Joint Embedding Predictive Architecture (JEPA) 思想，通过在嵌入空间中进行预测学习，从而增强模型的语义抽象能力。LLM-JEPA 的核心目标是在保持生成能力的同时，引入跨视图表示对齐约束。

2. 总体优化目标

LLM-JEPA 的训练目标定义为：

LLLM−JEPA=∑ℓ=2LLLLM(Text1:ℓ−1,Textℓ)+λ⋅d(Pred(Enc(Text)),Enc(Code))\mathcal{L}_{\rm LLM-JEPA}= \sum_{\ell=2}^{L}\mathcal{L}_{\rm LLM}({\rm Text}_{1:\ell-1},{\rm Text}_{\ell}) + \lambda \cdot d\big({\rm Pred}({\rm Enc}({\rm Text})), {\rm Enc}({\rm Code})\big) LLLM−JEPA​=ℓ=2∑L​LLLM​(Text1:ℓ−1​,Textℓ​)+λ⋅d(Pred(Enc(Text)),Enc(Code))

其中：

  • LLLM\mathcal{L}_{\rm LLM}LLLM​：标准自回归语言建模损失；
  • Enc(⋅){\rm Enc}(\cdot)Enc(⋅)：编码器，将输入映射到嵌入空间；
  • Pred(⋅){\rm Pred}(\cdot)Pred(⋅)：预测器，在嵌入空间中进行映射；
  • d(⋅,⋅)d(\cdot,\cdot)d(⋅,⋅)：嵌入空间中的距离度量；
  • λ≥0\lambda \ge 0λ≥0：权衡生成能力与抽象能力的超参数。

3. 多视图建模设定

设 Text{\rm Text}Text 与 Code{\rm Code}Code 为同一底层语义的两种不同视图，则 LLM-JEPA 的目标可以理解为：

Text⟶Code(in representation space){\rm Text} \longrightarrow {\rm Code} \quad \text{(in representation space)} Text⟶Code(in representation space)

需要强调的是，该预测发生在嵌入空间而非 token 空间。

4. 关键组件设计

4.1 编码器（Encoder）

编码器采用 LLM 本身的表示能力，定义为最后一层最后一个 token 的隐状态：

Enc(x)=hlast token(L){\rm Enc}(x) = h^{(L)}_{\text{last token}} Enc(x)=hlast token(L)​

由于自注意力机制的存在，若直接拼接输入 [Text,Code][{\rm Text}, {\rm Code}][Text,Code]，将导致跨视图信息泄露。因此采用以下策略：

  • 分别对 Text{\rm Text}Text 和 Code{\rm Code}Code 进行独立前向传播；
  • 分别获得 Enc(Text){\rm Enc}({\rm Text})Enc(Text) 和 Enc(Code){\rm Enc}({\rm Code})Enc(Code)。

该设计在训练阶段增加计算开销，但不影响推理过程。

4.2 度量函数（Metric）

在嵌入空间中，通常采用如下距离度量：

  • 余弦距离：

    d(x,y)=1−x⊤y∣x∣∣y∣d(x,y) = 1 - \frac{x^\top y}{|x||y|} d(x,y)=1−∣x∣∣y∣x⊤y​

  • 或 ℓ2\ell_2ℓ2​ 距离：

    d(x,y)=∣x−y∣2d(x,y) = |x - y|_2 d(x,y)=∣x−y∣2​

在实践中，余弦相似度因其尺度不变性更为常用。

4.3 预测器（Predictor）

预测器利用 LLM 的自回归结构，通过引入特殊 token 实现，无需额外参数模块。

具体形式为：

在输入序列末尾追加 kkk 个预测 token：

[Text,PRED1,…,PREDk][{\rm Text}, {\rm PRED}_1, \dots, {\rm PRED}_k] [Text,PRED1​,…,PREDk​]

定义预测器为最后一个预测 token 的表示：

Pred(Enc(x))=hlast PRED token(L){\rm Pred}({\rm Enc}(x)) = h^{(L)}_{\text{last PRED token}} Pred(Enc(x))=hlast PRED token(L)​

特殊情况：

  • 当 k=0k = 0k=0 时，

    Pred(x)=x{\rm Pred}(x) = x Pred(x)=x

该设计实现了权重共享（weight sharing），避免引入额外参数，同时利用 Transformer 的非线性建模能力。
