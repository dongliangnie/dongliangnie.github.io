Boosting Multimodal Large Language Models with Visual Tokens Withdrawal for Rapid Inference

  2026-05-22    paper_notes  VLM/LLM  VLM Pruner    VLM Pruner
  • 论文标题：Boosting Multimodal Large Language Models with Visual Tokens Withdrawal for Rapid
    Inference
  • github链接：lzhxmu/VTW: Code release for VTW (AAAI 2025 Oral)
  • 发表：AAAI 2025 oral

当前方法的问题

现有 MLLM 加速方法（如 LLaVA-PruMerge、FastV）通过 Token 精简来降低计算量，但存在四大缺陷：

问题 说明
缺乏灵活性 对不同问题使用相同的视觉 Token 表示图像，无法根据问题动态调整重要 Token（如 POPE 中同一图像不同问题关注不同区域）
重要性度量不完整 需手工设计重要性指标来裁剪 Token，缺乏理论依据，部分真正重要的 Token 被误剪
与 KV Cache 不兼容 FastV 动态剪枝导致之前 Token 的 KV Cache 无法复用，被剪 Token 仍占用内存，降低收益
与 Flash-attention 不一致 FastV 需存储注意力分数以判断 Token 重要性，而 Flash-attention 不提供此功能

本文方法：Visual Tokens Withdrawal (VTW)

核心发现

  1. 注意力下沉：MLLM 深层中，系统 Token 吸收了绝大部分注意力（~80%+），576 个视觉 Token 仅获 ~5% 注意力
  2. 信息迁移：视觉信息在 MLLM 前几层内已通过因果自注意力迁移到后续文本 Token 中

方法

在特定层 K 之后撤回所有视觉 Token，仅保留文本 Token（系统 + 指令 + 输出）参与深层计算：

撤回层 KKK 的搜索算法

  • 在目标数据集上采样小子集（20 样本）
  • 枚举 K 从 5 到 N，计算标准输出 logits 与 VTW 输出 logits 的 KL 散度
  • 选择第一个满足 KL < η（η=0.003）的层作为撤回层

思路

不同 MLLM 架构和不同任务所需的信息迁移层数不同。复杂任务可能需要更多层完成视觉信息到文本 Token 的迁移。因此，KKK 需要根据具体模型和数据集自适应确定。

搜索过程

选择准则

KL(lmhead(XN+1) ∥ lmhead(XN+1))<ηKL\big(lm_{head}(X_{N+1})\ \|\ lm_{head}(\mathcal{X}_{N+1})\big) < \eta KL(lmhead​(XN+1​) ∥ lmhead​(XN+1​))<η

  • lmhead(⋅)lm_{head}(\cdot)lmhead​(⋅)：LLM 的投影头（输出 logits）
  • XN+1X_{N+1}XN+1​：标准推理的最终输出（保留所有 Token）
  • XN+1\mathcal{X}_{N+1}XN+1​：VTW 推理的最终输出（第 K 层撤回视觉 Token）
  • η\etaη：KL 散度阈值，论文设为 0.003

消融实验结果

不同阈值 η\etaη 对应的 KKK 和准确率（SQA_Image, LLaVA-1.5-7B）：

η\etaη 0.006 0.005 0.004 0.003 0.002 0.001
KKK 12 13 14 15 15 15
Acc 69.01 69.26 69.46 69.70 69.70 69.70
  • KL 散度收敛后（K≥15K \geq 15K≥15），准确率稳定在基线水平 69.70%
  • 较小的 KKK 导致 KL 散度大，准确率明显下降
  • 论文选择 η=0.003\eta = 0.003η=0.003 作为默认阈值

优势

维度 优势
灵活性 所有视觉 Token 在前几层保留，不依赖问题动态选择
无需重要性度量 直接撤回所有视觉 Token，绝不误剪重要 Token
KV Cache 兼容 所有视觉 Token 同时被保留/移除，KV Cache 可正常复用
Flash-attention 兼容 无需存储注意力分数，直接适配 Flash-attention
