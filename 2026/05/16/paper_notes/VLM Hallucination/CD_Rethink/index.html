自适应合理性约束

上述方法在整个输出空间中进行无差别惩罚，可能会抑制有效预测，并引入不合理标记。为缓解这一问题，引入自适应合理性约束，根据原始视觉输入 vvv 条件下的模型输出分布动态调整惩罚范围。

自省解码

SID 的核心机制是：通过分析早期解码层中“文本 token 对图像 token”的注意力分布，识别出那些注意力较低、即模型在生成过程中几乎未依赖的图像区域（低 attention tokens），并认为这些区域缺乏有效的视觉约束、因此更容易引发基于语言先验的幻觉；随后，SID 构造一个裁剪后的输入，仅保留这些弱相关的图像 tokens、移除高注意力区域，从而主动诱导模型生成更具幻觉倾向的对比分布，为后续的对比解码提供针对性的抑制信号。

Insight

迎合了数据分布的偏向性

对比解码方法（VCD、SID）的性能变化，主要并非源于真实的幻觉抑制能力，而是由于对比分支本身引入的输出分布偏置（尤其是向“Yes”的单向偏移）；这种偏移在不同数据分布下可能“恰好”提升或降低准确率，因此其性能增益具有数据依赖性，甚至可能是一种表象（mirage），而非模型视觉理解能力的真实提升。

正是因为对比解码分支强烈的偏向否导致了对比结果强烈的偏向是。

自适应合理性约束让基于采样的解码退化为贪婪解码

值得注意的是，要求模型回答” 是” 或” 否” 的 POPE 基准本质上是一个二分类任务。因此，贪心搜索是最合适的解码策略，这使得基于采样的方法缺乏合理性，如图所示。实验结果进一步证实贪心搜索显著优于直接采样。事实上，贪心搜索在绝大多数任务上都优于直接采样。

由于 POPE 本质是二分类任务，贪心解码已是最优决策策略，而采样会引入不必要的随机性并改变输出分布。

自适应合理性约束原本只是用来限制候选空间的辅助机制，并不直接用于提升性能或缓解幻觉，因此通常认为单独使用它不会带来明显效果；但实验发现，在采样（sampling）解码下，它反而成为性能提升的关键。原因在于，采样会按照概率随机选取输出，即使正确答案概率很高，也仍可能选错，而该约束通过条件

pθ(yt∣v,x,y<t)≥βmax⁡wpθ(w∣v,x,y<t)p_\theta(y_t \mid v,x,y_{<t}) \ge \beta \max_{w} p_\theta(w \mid v,x,y_{<t}) pθ​(yt​∣v,x,y<t​)≥βwmax​pθ​(w∣v,x,y<t​)

过滤掉低概率候选，从而显著缩小候选集合。举例来说，对于问题“图像中是否有手机？”，模型输出分布为：P(Yes)=8.8P(\text{Yes}) = 8.8%P(Yes)=8.8，P(No)=91.2P(\text{No}) = 91.2%P(No)=91.2。在贪心策略下，总是选择“No”（始终正确），但在采样时有 8.88.8%8.8 的概率错误地输出“Yes”。如果设置 β=0.5\beta = 0.5β=0.5，则阈值为

0.5×91.20.5 \times 91.2% = 45.6% 0.5×91.2

此时“Yes”因不满足条件被过滤，只剩“No”一个候选，采样过程因此退化为贪心搜索，错误概率降为 000。因此，这种性能提升并不是因为更好地抑制了幻觉，而是因为该约束消除了采样带来的随机性，使解码行为变得近似确定性，从而获得更稳定、更高的准确率。

方法

作者提出了一系列虚假提升方法。尽管这些方法与缓解幻觉完全无关，但它们产生的结果与对比解码技术相当。

强制分布调整（Forced Distribution Adjustment）

针对性能提升的第一个误导性因素，即通过单向修改模型预测使输出分布偏向“Yes”，本文提出了两种伪性能提升方法：基于提示的调整（PBA）和输出层修改（OLM）。

1. 基于提示的调整（Prompt-Based Adjustment, PBA）

该方法通过在用户输入后附加额外提示（例如“尽可能回答是”）来修改输入，从而引导模型输出分布向“Yes”偏移。

2. 输出层修改（Output-Level Modification, OLM）

该方法在模型输出阶段进行干预。在生成初始预测后，模型计算“Yes”和“No”的概率。如果两者差异较小，即：

∣pθ(Yes∣v,x)−pθ(No∣v,x)∣<τ\left| p_\theta(\text{Yes} \mid v, x) - p_\theta(\text{No} \mid v, x) \right| < \tau ∣pθ​(Yes∣v,x)−pθ​(No∣v,x)∣<τ

则将最终预测强制设为“Yes”，其中：

  • τ\tauτ 为阈值超参数，用于控制触发该修改的概率接近程度

上述两种方法通过不同方式人为地增加模型输出“Yes”的概率，从而改变输出分布。这种分布偏移可能在某些数据集上带来表面上的性能提升，但并不代表模型视觉理解能力的真实增强。

如 Table 4 所示，对于判别任务 MME，对比解码方法没有带来任何性能增益，因为模型的输出没有表现出初始分布偏差。事实上，它导致了性能下降。类似地，在CHAIR、Nocaps 和 LLaVA-Bench 等生成任务中，对比解码也没有带来改进。这清楚地表明，对比解码只能在初始输出分布偏向” 否” 的判别任务中提升性能。然而，这种改进并不能从根本上解决物体幻觉问题。

约束的独立应用

讨论

  • 解码策略的影响：在 POPE 上评估时，必须考虑不同解码策略对模型性能的巨大影响。值得注意的是，贪心搜索始终优于基于采样的方法（如直接采样和核采样）。如果幻觉缓解方法涉及对采样模块的修改，必须仔细考虑这些更改是否影响了解码策略的核心特性。
  • 避免单向修改：在评估幻觉缓解方法时，必须评估它们是否单向地改变响应。鉴于多模态大语言模型在多个数据集上的输出分布存在偏斜，仅仅重新平衡响应的方法可能造成性能提升的假象。然而，这种调整并不能真正缓解幻觉。
  • 平衡修正与保持：有效的幻觉缓解方法必须达到平衡：它应该修正错误答案同时保持正确答案。然而，如 Figure 2 所示，一些有缺陷的方法尽管修正了许多错误，也对原本正确的响应引入了不必要的修改。这种行为更像是单纯的答案编辑而非真正的幻觉缓解。为提高评估的严谨性，未来的研究应明确报告正确响应被错误修改的情况，提供更清晰的方法真实有效性度量。
