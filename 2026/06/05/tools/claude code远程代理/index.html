npm

npm 是 Node Package Manager（Node.js 包管理器）的缩写，它是 JavaScript 世界中最主要的包管理和分发工具。

核心功能

1. 管理依赖包

  • 安装、更新、卸载第三方库和工具
  • 例如你之前尝试的 @anthropic-ai/claude-code 就是一个 npm 包

2. 版本管理

  • 精确控制项目依赖的版本
  • 自动处理包之间的版本依赖关系

3. 共享代码

  • 开发者可以发布自己的包到 npm 仓库
  • 其他人可以通过 npm 安装使用

主要组成部分

组件 说明
npm 官网 https://www.npmjs.com - 查找和浏览包的网站
npm registry 存储所有包的服务器（如 registry.npmjs.org）
npm CLI 命令行工具，就是你使用的 npm 命令

SSH 反向隧道

SSH 反向隧道命令的作用是将你本地（客户端）的端口暴露到远程云服务器上，让云服务器可以通过本地隧道访问你本地的服务。

参数 含义
-N 不执行远程命令，只建立隧道
-f 后台运行 SSH 连接
-R 反向隧道（Remote forward）
本地IP 通常填 localhost 或 127.0.0.1

工作原理

关键理解：

  • 云服务器上的程序连接到 localhost:7890，实际访问的是你本地的 7899 端口
  • 云服务器上的程序连接到 localhost:9999，实际访问的是你本地的 12345 端口

这个命令用于检查本地端口 9999 和 7890 的监听状态，是验证你的代理或隧道服务是否正常运行的常用方法。

Socket Statistics

参数 含义
ss Socket Statistics，比 netstat 更现代的网络工具
-t 只显示 TCP 端口
-l 只显示正在监听（LISTEN）的端口
-n 不解析服务名称，直接显示端口号（如显示 7890 而不是 http-alt）
-p 显示占用该端口的进程名称和 PID
grep -E 扩展正则匹配，筛选包含 9999 或 7890 的行

输出解读

正常情况下（端口已启用）

解读：

  • 0.0.0.0:7890 - 监听所有网络接口，允许外部连接
  • 127.0.0.1:9999 - 只监听本地回环地址，仅本机可访问
  • clash - 进程名，说明 7890 是 Clash 代理
  • sshd - 进程名，说明 9999 是 SSH 隧道转发的端口

无输出（端口未启用）

curl

检查是否可以正常访问外网

综合使用

举例1

部分 含义
timeout 10 整个命令最多执行 10 秒，防止卡住
curl HTTP 请求工具
-x http://127.0.0.1:7890 使用代理（你的 Clash HTTP 代理）
-s 静默模式，不显示进度条和错误信息
-o /dev/null 丢弃响应内容，只关心响应头
-w 自定义输出格式
'HTTP:%{http_code} TIME:%{time_total}s' 输出 HTTP 状态码和总耗时
https://api.anthropic.com 目标地址（Anthropic API）
2>&1 将错误输出重定向到标准输出（便于统一捕获）

✅ 成功情况

  • HTTP:200：代理工作正常，成功连接到 Anthropic API
  • TIME:0.523s：总耗时 0.5 秒，速度正常

❌ 失败情况及诊断

输出 含义 解决方案
HTTP:000 + 无 TIME 代理完全连不通 Clash 没启动或端口不对
HTTP:407 需要代理认证 在代理 URL 中添加用户名密码
HTTP:502/504 代理服务器无法连接目标 Clash 节点有问题，换一个节点
timeout:10 命令超时 代理响应太慢 网络不稳定，增加 timeout 值
curl: (7) Failed to connect 本地 7890 端口没有监听 先启动 Clash
